# RIO BOARD
Sinhala + English Android keyboard. Push to GitHub -> Actions builds the APK -> download from Releases.

## New in this version
- **Swipe typing** – glide across letters (English, or Singlish when it is on). Other guesses appear in the suggestion bar.
- **Next-word suggestions** (Sinhala + English, learns from you) and **Singlish auto-correct** (backspace right after undoes it).
- **One-handed mode** (left/right), keyboard **width** and **height** in Settings.
- **Number row toggle** and **long-press popups**: `a → á ä`, `1 → !`. With Singlish on, `t → T`, `n → N`, `l → L` ...
- **Layouts**: Sinhala grid, **Wijesekara** (SLS 1134, long-press ABC key or Settings to switch) and **Tamil**.
